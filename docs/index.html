Getting Help

If you found a problem with WhyUI, please open an issue in the project's GitHub repository. Include the Edge version, WhyUI version, the type of page or UI element involved, and steps to reproduce the issue.

Open a WhyUI support issue on GitHub

Common Troubleshooting

WhyUI does not appear: Check that the extension is enabled and pinned in Edge.

Element selection does not work: Refresh the page and try selecting the element again.

The explanation is incomplete: WhyUI uses deterministic browser-visible evidence and may not be able to determine private application business logic.

A page behaves differently: Some pages, cross-origin frames, closed shadow DOMs, and browser-restricted contexts may limit inspection.

Privacy

WhyUI is designed as a local-first developer tool. Page analysis is performed in the browser and the extension does not require an account or backend service.
