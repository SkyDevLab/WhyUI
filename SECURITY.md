# Security Policy for WhyUI

Published by **SkyDevLab**

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

WhyUI is committed to ensuring the security and privacy of web developers and users. The extension executes 100% locally and transmits zero network telemetry.

If you believe you have found a security vulnerability in WhyUI, please report it responsibly:

1. **Email**: Send vulnerability reports to `Pratapsinghsurya19@gmail.com` with the subject `[SECURITY] WhyUI Vulnerability Report`.
2. **Details to include**:
   - Description of the issue
   - Reproduction steps or proof of concept
   - Impact assessment
3. **Response Timeline**:
   - Acknowledgement within 48 hours
   - Status update within 5 business days
   - Release of patch following verified assessment

Please do not open public GitHub issues for security vulnerabilities until a patch has been published.
